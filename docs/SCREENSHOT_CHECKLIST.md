# Asclepius FairAI -- Screenshot & Visual Asset Checklist

This checklist documents the recommended screenshots for conference presentations, project posters, academic papers, and project documentation.

---

### Visual Design Guidelines
- **Color Palette**: Emerald Green (`#16A34A`), Dark Forest (`#15803D`), Soft Mint (`#ECFDF5`), Slate (`#0F172A`), and Crisp White.
- **Privacy Compliance**: All screenshots must utilize the synthetic demonstration dataset (`data/demo/synthetic_clinical_demo.csv`). Zero real Protected Health Information (PHI) is permitted.
